# Dataflow Gen2 Advisor

This is the solution entry folder for the Dataflow Gen2 analyzer.

## Start here

1. Import [DataflowGen2_Analyzer.ipynb](DataflowGen2_Analyzer.ipynb) into your Fabric workspace.
2. Review the notebook prerequisites and configure its Parameters cell.
3. Run the cells in order and review the generated findings and reports.

See the [full usage guide](../DataflowGen2_Advisor.md) for local CLI commands,
permissions, offline setup, rule coverage, and report formats.

## Compatibility

The Python package, packaging configuration, samples, and tests stay at the
[Analyzer root](../) so existing installation commands continue to work.
The [original notebook path](../notebooks/DataflowGen2_Analyzer.ipynb) is retained
for existing links and contains the same notebook as this solution folder.

Return to the [complete analyzer index](../README.md).
