# OneLake Shortcut Auditor

[OneLake Shortcut Auditor.ipynb](OneLake%20Shortcut%20Auditor.ipynb) discovers
shortcuts, checks connectivity, reviews workspace and Lakehouse access, and
summarizes findings.

1. Open the notebook in the intended Fabric environment.
2. Review configuration, authentication, workspace scope, and permissions.
3. Review optional Teams webhook alerts and Lakehouse persistence before running.
4. Run the cells in order and inspect the results.

The notebook is copied unchanged. Optional notification code can send a Teams
message when configured; optional persistence writes diagnostic results.
Shortcut-creation automation notebooks are intentionally not part of this audit
folder.
