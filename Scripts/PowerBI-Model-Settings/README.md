# PowerBI-Model-Settings

PowerShell scripts for semantic model connectivity and DirectQuery tuning.

## Files

- Set-PBIDirectQueryParallelism.ps1 - Sets DirectQuery parallelism to align throughput with gateway and source capacity.
- Set-SemanticModelMaxConnections.ps1 - Updates semantic model max connection settings for concurrency control.
