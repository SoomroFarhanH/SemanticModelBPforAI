# Scripts

Reusable PowerShell scripts grouped by operational purpose.

## Folders

- [PowerBI-Model-Settings](PowerBI-Model-Settings/) - Scripts that tune semantic model connection and DirectQuery behavior.
- [Utilities](Utilities/) - Utility scripts for supporting operations.
