# Notebooks

Scenario-based notebook collection for semantic model readiness, Copilot diagnostics, lakehouse operations, and business demos.

## Folders

- [SemanticModel-Optimization](SemanticModel-Optimization/) - Model quality, performance, and schema-shaping notebooks.
- [Lakehouse-OneLake](Lakehouse-OneLake/) - OneLake shortcut audit and automation notebooks.
- [Copilot-Agent-Insights](Copilot-Agent-Insights/) - Copilot and data agent quality/usage analysis notebooks.
- [Business-Demos](Business-Demos/) - Demo-oriented notebooks for architecture and business reporting.
