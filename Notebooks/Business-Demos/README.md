# Business-Demos

Demo notebooks focused on business-facing storytelling and architecture conversion.

## Files

- CFO Dashboard.ipynb - CFO-focused dashboard analysis and KPI exploration notebook.
- Meeting Notes to Architecture.ipynb - Converts unstructured meeting notes into architecture-oriented outputs.
