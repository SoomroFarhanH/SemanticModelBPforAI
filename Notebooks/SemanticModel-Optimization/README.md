# SemanticModel-Optimization

Notebooks focused on semantic model optimization and AI/Copilot readiness.

## Files

- DirectQuery_BestPractices_Check.ipynb - Checks DirectQuery model settings against recommended practices.
- DirectQuery_BestPractices_Check_TabularEditor2.cs - Runs the DirectQuery checks from the Tabular Editor 2 Advanced Scripting tab.
- fact_sale_row_group_guidance.ipynb - Evaluates fact table row-group guidance for performance and storage behavior.
- Semantic Model Report AnalyzerMK.ipynb - Analyzes semantic model/report metadata to surface quality and design insights.
- SemanticModel_DAX_to_Excel_Paginated_Style.ipynb - Exports DAX query output in paginated-style Excel formatting.
- SemanticModel_DAX_to_Excel_Paginated_Style_Batch.ipynb - Batch variant of DAX-to-Excel paginated export.
- SimplifySchemaForAI.ipynb - Simplifies semantic model schema patterns for better AI interpretation.
