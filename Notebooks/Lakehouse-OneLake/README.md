# Lakehouse-OneLake

Notebooks for OneLake shortcut governance, auditing, and automation.

## Files

- OneLake Shortcut Auditor.ipynb - Audits shortcut inventory and flags potential governance issues.
- onelake-shortcut-automation.ipynb - Automates shortcut setup and maintenance workflows.
- onelake-shortcut-automation-fabcli.ipynb - Shortcut automation workflow tailored for Fabric CLI usage.
