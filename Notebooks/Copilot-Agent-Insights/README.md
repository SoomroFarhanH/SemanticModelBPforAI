# Copilot-Agent-Insights

Notebooks for measuring Copilot and data agent quality, usage, and readiness.

## Files

- Agent Quality Evaluator.ipynb - Evaluates agent responses and readiness signals against quality criteria.
- Copilot SKU Estimator.ipynb - Estimates Copilot or capacity SKU needs from workload assumptions.
- Fabric Copilot Question Mining.ipynb - Mines user questions to identify prompt, schema, and enablement opportunities.
